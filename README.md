# Кулинарный калькулятор рецептов

Проект имеет набор классов на Python для работы с ингредиентами, рецептами и автоматическим составлением списка покупок. Программа умеет масштабировать количество ингредиентов в зависимости от нужного количества порций, суммировать одинаковые продукты и объединять списки покупок.

## Как запускать код

Весь основной код с классами должен находиться в файле `main.py`. Чтобы использовать эти классы в своем скрипте, просто импортируйте их:

```python
from main import Ingredient, Recipe, ShoppingList, DietaryRecipe
## Сейчас будет примерчик!!!
## Создаем ингредиенты
ing1 = Ingredient("Мука", 500.0, "г")
ing2 = Ingredient("Яйца", 2.0, "шт")

# Создаем рецепт
recipe = Recipe("БЛИНчики с вЭтчиной и сиром", [ing1, ing2])

# Добавляем в список покупок на 2 порции
sl = ShoppingList()
sl.add_recipe(recipe, 2.0)

# Получаем итоговый список
print(sl.get_list())
